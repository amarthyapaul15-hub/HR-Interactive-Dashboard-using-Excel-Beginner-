# HR-Interactive-Dashboard-using-Excel-Beginner
A beginner-level Excel project exploring interactive HR dashboard creation. It uses charts, summary metrics, and slicers to analyze employee headcount, demographics, tenure, performance ratings, and wage rates while building my skills in HR analytics and data visualization.
## Tools Used
- Microsoft Excel
- PivotTables and charts
- Interactive slicers
- ## Key Features
- Employee headcount and average age
- Average tenure and prior experience
- Performance ratings and wage rates
- Interactive filters for employee attributes

## What I Learned
This project helped me practice Excel data analysis, data visualization, and building interactive dashboards for HR reporting.
